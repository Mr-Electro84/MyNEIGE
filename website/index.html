UN VPN À SA PLACE

Votre campus sous VPN.
Le reste suit son cours.

MyNEIGE réserve le tunnel aux accès universitaires qui en ont besoin. Vos autres applications gardent leur connexion Internet habituelle, leur routage et leur DNS.

Si le VPN ou son relais s’arrête, les accès protégés sont bloqués : ils ne basculent pas vers votre connexion habituelle.

Dans MyNEIGE, Mail/PARTAGE, RENATER et les lecteurs externes autorisés utilisent aussi la connexion habituelle. Les services protégés restent sous VPN.

QUELQUES PRÉCISIONS

Avant votre
première connexion.

Lire le guide d’utilisation ↗
Dois-je saisir deux fois mon mot de passe ?

Non. Les identifiants saisis dans MyNEIGE servent à démarrer le VPN, puis sont préremplis une seule fois sur la page d’authentification universitaire vérifiée. Vous cliquez vous-même sur « SE CONNECTER » : le formulaire n’est jamais soumis automatiquement.

Windows Hello est-il obligatoire ?

Non. La saisie manuelle reste disponible. Windows Hello sert à réutiliser les identifiants que vous avez choisi d’enregistrer sur ce PC. Votre code PIN et vos données biométriques sont traités par Windows, jamais par MyNEIGE.

Le VPN modifie-t-il la connexion de mes autres applications ?

Non. Le tunnel est limité aux accès protégés de MyNEIGE. Le proxy système, le DNS global et les routes par défaut de votre connexion physique ne sont pas modifiés pour faire fonctionner l’application.

Comment se termine une session ?

Fermer le formulaire MyNEIGE met fin à la session. Dans cette Alpha, elle s’arrête aussi après 30 minutes. La compatibilité avec la veille, les changements de réseau et les autres VPN reste à qualifier.

MyNEIGE est-il disponible sur macOS ou Linux ?

Cette version est destinée à Windows 11 x64, sur processeur Intel ou AMD. Aucune version macOS, Linux ou Windows ARM n’est proposée ici.
